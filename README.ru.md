# LocalMuteFilter

**Language / Язык:** [English](README.md) · Русский

Плагин для BetterDiscord, который локально заглушает всех в текущем голосовом канале, кроме тех, кого ты явно внес в белый список — и снимает мьюты, как только ты выходишь.

---

## Проблема

В определенных активностях есть нужда слышать только конкретную группу лиц в канале на какой-то период времени. Причем из этапа к этапу в активности группа лиц может меняться ввиду перестановки ролей участников. И вручную каждый раз выставлять локальный мут превращается в рутину и задачу поиска нужного пользователя.

По окончании активности желательно бы снимать такие выставленные локальные мути. И придется снова прокликивать всех, чтобы снять эту заглушку.

## Идея

**LocalMuteFilter переворачивает эту логику.** Вместо списка тех, кого надо заглушить, ты ведешь список тех, кого надо *оставить*. Все остальные в канале заглушаются автоматически — локально, только для твоего клиента. Никто другой этого не видит, права на сервере не трогаются, остальные участники вообще не в курсе.

## Как это работает

1. Ты вставляешь список ID пользователей Discord в панели настроек плагина.
2. Когда ты заходишь в голосовой канал, плагин проверяет каждого участника:
   - В белом списке → локальный мьют **снимается**.
   - Не в белом списке → локальный мьют **ставится**.
3. Когда кто-то заходит или выходит из канала, правило применяется к текущему каналу заново.
4. Когда *ты* выходишь из канала или переходишь в другой, все мьюты, поставленные плагином, **снимаются**, а к новому каналу правило применяется с нуля.
5. Когда ты выключаешь плагин, все его мьюты **снимаются**.

Плагин не опрашивает состояние по таймеру. Он подписывается на внутренний `VoiceStateStore` Discord и реагирует только на реальные события (вход / выход / перемещение / изменение состояния мьюта), с небольшим debounce, чтобы сгладить всплески.

## Почему локальный мьют

*Локальный* мьют в Discord — это переключатель на стороне клиента: он заглушает пользователя только для тебя. Это не серверный мьют, не self-mute, и он не требует никаких прав. Это ровно та галочка, которую ты видишь в контекстном меню пользователя под пунктом «Заглушить» — плагин просто автоматизирует ее нажатие.

Благодаря этому плагин безопасен где угодно: на серверах, в личных сообщениях, в групповых звонках. Кроме тебя, никто не затронут.

## Семантика белого списка

Белый список — **единственный источник истины**:

- Если пользователь в белом списке, плагин гарантирует, что он *не* заглушен локально им.
- Если пользователь не в белом списке, плагин гарантирует, что он *заглушен* локально.
- Когда ты выходишь из канала, плагин снимает все мьюты, которые поставил.

## Настройка

Вся настройка происходит через панель настроек плагина в BetterDiscord. Редактировать файлы не нужно.

- **ID пользователей** — по одному в строке или через запятую. Только цифры, 17–20 символов. Некорректные значения отбрасываются и показываются в панели.

Как скопировать ID пользователя: включи **Режим разработчика** в настройках Discord (Настройки → Расширенные → Режим разработчика), затем щелкни правой кнопкой по пользователю и выбери **Copy User ID** (Скопировать ID пользователя).

## Требования

- Десктопный клиент Discord
- Установленный [BetterDiscord](https://betterdiscord.app/)

## Установка

1. Установи BetterDiscord.
2. Открой Discord → Настройки → BetterDiscord → Plugins.
3. Нажми **Open Plugin Folder**.
4. Положи файл `LocalMuteFilter.plugin.js` в эту папку.
5. Включи плагин в списке Plugins.
6. Нажми иконку шестеренки рядом с названием плагина, чтобы открыть настройки.

## Замечания и ограничения

- Плагин опирается на внутренние Webpack-модули Discord (`MediaEngineStore`, `VoiceStateStore`, `UserStore` и модуль, экспортирующий `toggleLocalMute`). Это не публичный API, и он может меняться между обновлениями Discord. Если после обновления плагин перестанет работать, возможно, потребуется поправить поиск модулей.
- Локальные мьюты существуют на стороне клиента. Плагин заново применяет правило при каждом входе в канал.
- Плагин никак не изменяет твой аккаунт, настройки сервера или опыт других пользователей.
